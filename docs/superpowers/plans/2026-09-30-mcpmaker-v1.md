# mcpmaker v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Python package where `mount_mcp(app)` exposes a FastAPI app as an MCP server at `/mcp`, and a `mcpmaker` CLI that connects it to AI clients (`connect`), verifies it (`doctor`), proxies any OpenAPI API (`serve`), and bridges stdio-only clients (`bridge`).

**Architecture:**
- The policy that decides which routes become tools and what they're called is pure Python, and it works on OpenAPI operations, so the in-app mount and the standalone `serve` share it.
- `engine.py` is the only module that imports FastMCP 3.x. It builds the server from `(spec, httpx client)`:
  - for the in-app mount, the client uses an in-process `ASGITransport`
  - for `serve`, it's a network client
- Auth pass-through and HTTP error shaping are done with httpx event hooks plus a FastMCP middleware.
- Client adapters edit each AI client's config file safely (merge, backup, atomic write). Claude Code is set up through its own `claude mcp add` CLI instead.

**Tech Stack:** Python ≥3.10, FastAPI, FastMCP `>=3.2,<4`, httpx, Typer, uvicorn, PyYAML, pytest + pytest-asyncio.

**Spec:** `docs/superpowers/specs/2026-09-30-mcpmaker-v1-design.md` (decision log: `versionideas.md`)

## Global Constraints

- **No GitHub:** local git only. Never add a remote, push, open PRs, or create `.github/` files.
- Python `>=3.10`. All shell commands assume the project venv is active (`.venv\Scripts\activate` on Windows, `source .venv/bin/activate` elsewhere).
- FastMCP `>=3.2,<4`, imported **only** in `src/mcpmaker/engine.py`. Tests may import `fastmcp` directly.
- Route defaults:
  - GET exposed
  - POST/PUT/PATCH/DELETE hidden unless `include_writes=True` or `openapi_extra={"x-mcp": True}`
  - `openapi_extra={"x-mcp": False}` and `exclude` globs always hide
- Tool names: `[a-zA-Z0-9_-]{1,64}`. The endpoint's Python function name is preferred, then the operationId. Collisions get `_2`, `_3`, and a warning.
- Header **values** are never logged, and never appear in `MountReport` or in `doctor`/`connect` output. Forwarded by default: `Authorization`, `Cookie`, plus any `forward_headers`.
- Tool-call error text: `HTTP <status>: <body truncated to 4096 chars>`. For 401/403, add the line `auth failed - check the header configured in your client; run \`mcpmaker doctor\``. For route exceptions, use exactly `GENERIC_ERROR` and never include traceback text.
- Config edits always follow: parse → merge (other servers untouched) → `*.bak` backup → temp file + `os.replace`. Malformed config is never overwritten without `--force`.
- CLI status markers are ASCII only: `OK`, `FAIL`, `--`. CLI output must be ASCII-encodable.
- Doctor exits non-zero if any check is `FAIL`. `connect` exits non-zero if any install `failed`.

## Review Focus

1. **VS Code `mcp.json` with `//` comments (JSONC).** The user expects the file not to be clobbered: `connect` reports `failed` with a copy-paste snippet and leaves the file byte-identical. The test is in Task 6.
2. **Secrets leaking into logs.** A Bearer token sent by the client must not appear in any `mcpmaker` log record or in `MountReport.format()`. The test is in Task 4 (`test_token_never_logged`).
3. **Running `connect` twice.** The user expects exactly one entry, a `.bak` backup, and status `replaced`, not a duplicate or a crash. The test is in Task 9 (`test_connect_twice_is_idempotent`).
4. **Non-ASCII output on legacy Windows consoles.** `connect` and `doctor` output must encode as ASCII. Tests are in Task 8 and Task 9 (`.encode("ascii")` assertions).
5. **Routes registered after `mount_mcp(app)`.** They still become tools, because the server is built at startup. The test is in Task 4 (`test_routes_added_after_mount_are_exposed`).

```python
"""Decide which OpenAPI operations become MCP tools, and what they're called.

Pure functions: no FastAPI, no FastMCP. Shared by `mount_mcp` and `mcpmaker serve`.
"""

from __future__ import annotations

import copy
import fnmatch
import re
from dataclasses import dataclass, field
from typing import Any, Mapping, Sequence

HTTP_METHODS = ("get", "put", "post", "delete", "options", "head", "patch", "trace")
WRITE_METHODS = frozenset({"POST", "PUT", "PATCH", "DELETE"})

WRITE_REASON = "write method (pass include_writes=True or set openapi_extra={'x-mcp': True})"
EXCLUDED_REASON = "excluded"
MCP_PATH_REASON = "mcp endpoint"
METHOD_REASON = "unsupported method"

MAX_NAME_LEN = 64
_BAD_NAME_CHARS = re.compile(r"[^a-zA-Z0-9_-]")


@dataclass(frozen=True)
class Operation:
    operation_id: str
    method: str  # upper-case
    path: str
    summary: str = ""
    description: str = ""
    x_mcp: bool | None = None
    function_name: str | None = None


@dataclass(frozen=True)
class Hidden:
    operation: Operation
    reason: str


@dataclass
class Selection:
    operations: dict[str, Operation]
    exposed: dict[str, str] = field(default_factory=dict)  # operation_id -> tool name
    hidden: list[Hidden] = field(default_factory=list)
    warnings: list[str] = field(default_factory=list)


def sanitize_name(raw: str) -> str:
    name = _BAD_NAME_CHARS.sub("_", raw).strip("_") or "tool"
    return name[:MAX_NAME_LEN]


def ensure_operation_ids(spec: Mapping[str, Any]) -> dict[str, Any]:
    """Return a deep copy of `spec` in which every operation has an operationId."""
    out = copy.deepcopy(dict(spec))
    for path, item in (out.get("paths") or {}).items():
        for method in HTTP_METHODS:
            op = item.get(method)
            if isinstance(op, dict) and not op.get("operationId"):
                op["operationId"] = sanitize_name(f"{method}_{path}")
    return out


def operations_from_spec(
    spec: Mapping[str, Any],
    endpoint_names: Mapping[tuple[str, str], str] | None = None,
) -> list[Operation]:
    """List operations in `spec`. Every operation must have an operationId (see ensure_operation_ids)."""
    endpoint_names = endpoint_names or {}
    ops: list[Operation] = []
    for path, item in (spec.get("paths") or {}).items():
        for method in HTTP_METHODS:
            raw = item.get(method)
            if not isinstance(raw, dict):
                continue
            upper = method.upper()
            x_mcp = raw.get("x-mcp")
            ops.append(
                Operation(
                    operation_id=raw["operationId"],
                    method=upper,
                    path=path,
                    summary=raw.get("summary") or "",
                    description=raw.get("description") or "",
                    x_mcp=x_mcp if isinstance(x_mcp, bool) else None,
                    function_name=endpoint_names.get((upper, path)),
                )
            )
    return ops


def select_operations(
    operations: Sequence[Operation],
    *,
    include_writes: bool = False,
    exclude: Sequence[str] = (),
    mount_path: str = "/mcp",
    max_tools_warning: int = 40,
) -> Selection:
    sel = Selection(operations={op.operation_id: op for op in operations})
    used: set[str] = set()
    undocumented: list[str] = []

    for op in operations:
        reason = _hidden_reason(op, include_writes, exclude, mount_path)
        if reason is not None:
            sel.hidden.append(Hidden(op, reason))
            continue
        base = sanitize_name(op.function_name or op.operation_id)
        name = _dedupe(base, used)
        if name != base:
            sel.warnings.append(f"tool name collision: {op.method} {op.path} renamed '{base}' -> '{name}'")
        used.add(name)
        sel.exposed[op.operation_id] = name
        if not (op.summary or op.description):
            undocumented.append(name)

    if undocumented:
        sel.warnings.append(f"{len(undocumented)} tools have no description: {', '.join(undocumented)}")
    count = len(sel.exposed)
    if count > max_tools_warning:
        sel.warnings.append(
            f"{count} tools exposed; models pick tools less reliably above {max_tools_warning}. "
            "Consider exclude=[...]"
        )
    if count == 0:
        writes = sum(1 for h in sel.hidden if h.reason == WRITE_REASON)
        if writes:
            sel.warnings.append(
                f"0 tools exposed: {writes} write routes are hidden - pass include_writes=True "
                "or mark routes with openapi_extra={'x-mcp': True}"
            )
        else:
            sel.warnings.append("0 tools exposed: no routes matched")
    return sel


def _hidden_reason(op: Operation, include_writes: bool, exclude: Sequence[str], mount_path: str) -> str | None:
    mount = mount_path.rstrip("/")
    if op.path == mount or op.path.startswith(mount + "/"):
        return MCP_PATH_REASON
    if op.x_mcp is False or any(fnmatch.fnmatchcase(op.path, pattern) for pattern in exclude):
        return EXCLUDED_REASON
    if op.x_mcp is True or op.method == "GET":
        return None
    if op.method in WRITE_METHODS:
        return None if include_writes else WRITE_REASON
    return METHOD_REASON


def _dedupe(base: str, used: set[str]) -> str:
    if base not in used:
        return base
    n = 2
    while True:
        suffix = f"_{n}"
        candidate = base[: MAX_NAME_LEN - len(suffix)] + suffix
        if candidate not in used:
            return candidate
        n += 1
```

```python
"""How the MCP caller's credentials reach the user's API routes.

Every module that needs auth headers goes through an AuthProvider; v2 OAuth is a second implementation.
"""

from __future__ import annotations

from typing import Mapping, Protocol, Sequence

DEFAULT_FORWARD = ("authorization", "cookie")


class AuthProvider(Protocol):
    def headers_for(self, incoming: Mapping[str, str]) -> dict[str, str]:
        """Headers to send to the API route, given the inbound MCP HTTP request headers."""
        ...


class PassThroughAuth:
    def __init__(self, forward_headers: Sequence[str] = ()) -> None:
        names = (*DEFAULT_FORWARD, *(h.lower() for h in forward_headers))
        self.names = tuple(dict.fromkeys(names))

    def headers_for(self, incoming: Mapping[str, str]) -> dict[str, str]:
        lowered = {k.lower(): v for k, v in incoming.items()}
        return {name: lowered[name] for name in self.names if name in lowered}


def parse_header(raw: str) -> tuple[str, str]:
    name, sep, value = raw.partition(":")
    if not sep or not name.strip():
        raise ValueError(f"invalid header {raw!r}: expected 'Name: value'")
    return name.strip(), value.strip()
```

```python
    tools: list[tuple[str, str, str]] = field(default_factory=list)  # (tool, METHOD, path)
    hidden: list[tuple[str, str, str]] = field(default_factory=list)  # (METHOD, path, reason)
    skipped: list[tuple[str, str]] = field(default_factory=list)  # (operation_id, error)
    warnings: list[str] = field(default_factory=list)

    @classmethod
    def from_selection(cls, selection: Selection, *, path: str, skipped: list[tuple[str, str]]) -> MountReport:
        skipped_ids = {op_id for op_id, _ in skipped}
        tools = [
            (name, selection.operations[op_id].method, selection.operations[op_id].path)
            for op_id, name in selection.exposed.items()
            if op_id not in skipped_ids
        ]
        hidden = [(h.operation.method, h.operation.path, h.reason) for h in selection.hidden]
        warnings = list(selection.warnings) + [f"skipped {op_id}: {err}" for op_id, err in skipped]
        return cls(path=path, tools=tools, hidden=hidden, skipped=list(skipped), warnings=warnings)

    def format(self) -> str:
        head = f"mcpmaker: {len(self.tools)} tools exposed at {self.path}"
        writes_hidden = sum(1 for _, _, reason in self.hidden if reason == WRITE_REASON)
        if writes_hidden:
            head += f" ({writes_hidden} write routes hidden - pass include_writes=True or mark routes)"
        lines = [head]
        lines += [f"  - {name}  {method} {path}" for name, method, path in self.tools]
        lines += [f"  WARNING: {w}" for w in self.warnings]
        return "\n".join(lines)
```

```python
"""The only module that imports FastMCP. Everything FastMCP-specific lives here."""

from __future__ import annotations

import contextvars
import logging
from typing import Any, Callable, Mapping, TypeVar

import httpx
from fastmcp import FastMCP
from fastmcp.exceptions import ToolError
from fastmcp.server.dependencies import get_http_headers
from fastmcp.server.middleware import Middleware
from fastmcp.server.providers.openapi import MCPType

from mcpmaker.auth import AuthProvider
from mcpmaker.policy import Selection

log = logging.getLogger("mcpmaker")

AUTH_HINT = "auth failed - check the header configured in your client; run `mcpmaker doctor`"
GENERIC_ERROR = "internal error while calling the API route (details are in the server log)"
MAX_BODY = 4096

T = TypeVar("T")

# Per-tool-call scratch space shared between the error middleware and the httpx hooks.
_call_state: contextvars.ContextVar[dict[str, Any] | None] = contextvars.ContextVar(
    "mcpmaker_call_state", default=None
)


def make_api_client(
    *,
    base_url: str,
    auth: AuthProvider,
    transport: httpx.AsyncBaseTransport | None = None,
    timeout: float = 30.0,
) -> httpx.AsyncClient:
    async def forward_auth(request: httpx.Request) -> None:
        state = _call_state.get()
        if state is not None:
            state["sent"] = True
        try:
            incoming = get_http_headers(include_all=True)
        except Exception:  # no active MCP HTTP request, e.g. the in-memory transport
            incoming = {}
        for name, value in auth.headers_for(incoming).items():
            request.headers[name] = value

    async def record_response(response: httpx.Response) -> None:
        state = _call_state.get()
        if state is None:
            return
        state["status"] = response.status_code
        if response.status_code >= 400:
            await response.aread()
            state["body"] = response.text[:MAX_BODY]

    return httpx.AsyncClient(
        base_url=base_url,
        transport=transport,
        timeout=timeout,
        event_hooks={"request": [forward_auth], "response": [record_response]},
    )


class _ErrorShaping(Middleware):
    async def on_call_tool(self, context, call_next):
        state: dict[str, Any] = {}
        token = _call_state.set(state)
        try:
            return await call_next(context)
        except Exception as exc:
            raise ToolError(_error_message(context.message.name, state, exc)) from None
        finally:
            _call_state.reset(token)


def _error_message(tool: str, state: Mapping[str, Any], exc: BaseException) -> str:
    status = state.get("status")
    if status is not None and status >= 400:
        message = f"HTTP {status}: {state.get('body', '')}".rstrip()
        if status in (401, 403):
            message += f"\n{AUTH_HINT}"
        return message
    if state.get("sent"):
        # The request reached the route and it blew up: log everything, tell the model nothing internal.
        log.error("mcpmaker: tool %r failed inside the API route", tool, exc_info=exc)
        return GENERIC_ERROR
    # Failed before any HTTP request (e.g. bad arguments): the message is safe and useful to the model.
    return str(exc) or GENERIC_ERROR


def build_with_fallback(
    names: Mapping[str, str], attempt: Callable[[Mapping[str, str]], T]
) -> tuple[T, list[tuple[str, str]]]:
    """Build with all operations; if that fails, find and drop the ones that can't be built."""
    try:
        return attempt(names), []
    except Exception:
        pass
    kept = dict(names)
    skipped: list[tuple[str, str]] = []
    for op_id, tool in names.items():
        try:
            attempt({op_id: tool})
        except Exception as exc:
            skipped.append((op_id, f"{type(exc).__name__}: {exc}"))
            del kept[op_id]
    try:
        return attempt(kept), skipped
    except Exception as exc:
        skipped += [(op_id, f"{type(exc).__name__}: {exc}") for op_id in kept]
        return attempt({}), skipped


def build_server(
    spec: Mapping[str, Any],
    *,
    name: str,
    selection: Selection,
    client: httpx.AsyncClient,
) -> tuple[FastMCP, list[tuple[str, str]]]:
    def attempt(names: Mapping[str, str]) -> FastMCP:
        allowed = dict(names)

        def route_map_fn(route, mcp_type):
            return MCPType.TOOL if route.operation_id in allowed else MCPType.EXCLUDE

        server = FastMCP.from_openapi(
            openapi_spec=dict(spec),
            client=client,
            name=name,
            route_map_fn=route_map_fn,
            mcp_names=allowed,
        )
        server.add_middleware(_ErrorShaping())
        return server

    return build_with_fallback(selection.exposed, attempt)
```

```python
def free_port() -> int:
    with socket.socket() as s:
        s.bind(("127.0.0.1", 0))
        return s.getsockname()[1]


@contextmanager

    deadline = time.time() + 15
```

```python
"""`mount_mcp(app)`: serve the app's own routes as MCP tools at /mcp."""

from __future__ import annotations

import logging
from contextlib import asynccontextmanager
from dataclasses import dataclass
from typing import Sequence

import httpx
from fastapi import FastAPI
from starlette.responses import PlainTextResponse
from starlette.routing import Route

from mcpmaker.auth import AuthProvider, PassThroughAuth
from mcpmaker.engine import build_server, make_api_client
from mcpmaker.introspect import endpoint_names
from mcpmaker.policy import operations_from_spec, select_operations
from mcpmaker.report import MountReport

INTERNAL_BASE_URL = "http://mcpmaker.internal"


@dataclass
class MountHandle:
    path: str
    report: MountReport | None = None  # set when the app starts


class _LazyMCPApp:
    """ASGI app registered at `path`; forwards to the real MCP app once startup has built it."""

    def __init__(self) -> None:
        self.inner = None

    async def __call__(self, scope, receive, send) -> None:
        if self.inner is not None:
            await self.inner(scope, receive, send)
        elif scope["type"] == "http":
            response = PlainTextResponse(
                "mcpmaker: MCP server not started yet (the app's lifespan has not run)", status_code=503
            )
            await response(scope, receive, send)


def mount_mcp(
    app: FastAPI,
    *,
    path: str = "/mcp",
    name: str | None = None,
    include_writes: bool = False,
    exclude: Sequence[str] = (),
    forward_headers: Sequence[str] = (),
    auth: AuthProvider | None = None,
    max_tools_warning: int = 40,
) -> MountHandle:
    if not path.startswith("/") or path.endswith("/"):
        raise ValueError(f"path must start with '/' and not end with '/': {path!r}")
    auth = auth or PassThroughAuth(forward_headers)
    handle = MountHandle(path=path)
    lazy = _LazyMCPApp()
    # An exact-path Route (not a Mount) so clients never see a /mcp -> /mcp/ redirect.
    app.router.routes.insert(0, Route(path, endpoint=lazy, include_in_schema=False))

    original_lifespan = app.router.lifespan_context

    @asynccontextmanager
    async def lifespan(asgi_app):
        async with original_lifespan(asgi_app) as state:
            # Built at startup so routes registered after mount_mcp() are included.
            spec = app.openapi()
            selection = select_operations(
                operations_from_spec(spec, endpoint_names(app)),
                include_writes=include_writes,
                exclude=exclude,
                mount_path=path,
                max_tools_warning=max_tools_warning,
            )
            client = make_api_client(
                base_url=INTERNAL_BASE_URL, auth=auth, transport=httpx.ASGITransport(app=app)
            )
            server, skipped = build_server(spec, name=name or app.title, selection=selection, client=client)
            mcp_app = server.http_app(path=path)
            handle.report = MountReport.from_selection(selection, path=path, skipped=skipped)
            _logger().info("%s", handle.report.format())
            async with mcp_app.lifespan(mcp_app):
                lazy.inner = mcp_app
                try:
                    yield state
                finally:
                    lazy.inner = None
                    await client.aclose()

    app.router.lifespan_context = lifespan
    return handle

    log = logging.getLogger("mcpmaker")
    # Make the startup report visible under uvicorn, which doesn't configure the root logger.
    if not log.handlers and not logging.getLogger().handlers:
        handler = logging.StreamHandler()
        handler.setFormatter(logging.Formatter("%(message)s"))
        log.addHandler(handler)
        log.setLevel(logging.INFO)
    return log
```

```python
"""Read and write AI-client JSON config files without ever corrupting them."""

from __future__ import annotations

import json
import os
import re
import shutil
import tempfile
from pathlib import Path
from typing import Any, Literal, Mapping

ValueStyle = Literal["env", "keep", "literal"]
_VAR = re.compile(r"\$\{([A-Za-z_][A-Za-z0-9_]*)\}")


class ConfigError(Exception):
    pass


class MissingEnvVar(ConfigError):
    pass


def load_json(path: Path) -> dict[str, Any]:
    if not path.exists():
        return {}
    text = path.read_text(encoding="utf-8-sig")
    if not text.strip():
        return {}
    try:
        data = json.loads(text)
    except json.JSONDecodeError as exc:
        raise ConfigError(f"{path} is not valid JSON (line {exc.lineno}, column {exc.colno}: {exc.msg})") from None
    if not isinstance(data, dict):
        raise ConfigError(f"{path} must contain a JSON object at the top level")
    return data


def write_json_atomic(path: Path, data: Mapping[str, Any], *, backup: bool = True) -> Path | None:
    path.parent.mkdir(parents=True, exist_ok=True)
    backup_path = None
    if backup and path.exists():
        backup_path = path.with_name(path.name + ".bak")
        shutil.copy2(path, backup_path)
    fd, tmp = tempfile.mkstemp(dir=path.parent, prefix=f".{path.name}.", suffix=".tmp")
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as fh:
            json.dump(data, fh, indent=2)
            fh.write("\n")
        os.replace(tmp, path)
    except BaseException:
        Path(tmp).unlink(missing_ok=True)
        raise
    return backup_path


def render_value(value: str, style: ValueStyle) -> tuple[str, bool]:
    """Render a header value containing ${VAR} references for a client's config syntax."""
    if style == "keep":
        return value, False
    if style == "env":
        return _VAR.sub(lambda m: "${env:" + m.group(1) + "}", value), False
    names = _VAR.findall(value)
    missing = [n for n in names if n not in os.environ]
    if missing:
        raise MissingEnvVar(f"environment variable(s) not set: {', '.join(missing)}")
    return _VAR.sub(lambda m: os.environ[m.group(1)], value), bool(names)
```

```python
"""Shared types and the JSON-config adapter base class."""

from __future__ import annotations

import json
import os
import sys
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any, Literal, Mapping, Protocol

from mcpmaker.configio import ConfigError, ValueStyle, load_json, render_value, write_json_atomic

Status = Literal["installed", "replaced", "skipped", "failed"]


@dataclass(frozen=True)
class ServerEntry:
    name: str
    url: str
    headers: dict[str, str] = field(default_factory=dict)  # raw values; may contain ${VAR}


@dataclass(frozen=True)
class InstallResult:
    client: str
    status: Status
    path: str | None = None
    message: str = ""


class ClientAdapter(Protocol):
    name: str
    display_name: str
    reload_hint: str

    def detect(self) -> bool: ...
    def config_path(self) -> Path: ...
    def list_entries(self) -> dict[str, dict[str, Any]]: ...
    def url_of(self, block: Mapping[str, Any]) -> str | None: ...
    def check_entry(self, block: Mapping[str, Any]) -> str | None: ...
    def install(self, entry: ServerEntry, *, replace: bool = False, force: bool = False) -> InstallResult: ...


def app_config_dir() -> Path:
    """Per-user application config dir: %APPDATA%, ~/Library/Application Support, or XDG config."""
    if sys.platform == "win32":
        return Path(os.environ["APPDATA"])
    if sys.platform == "darwin":
        return Path.home() / "Library" / "Application Support"
    return Path(os.environ.get("XDG_CONFIG_HOME") or Path.home() / ".config")


def render_headers(headers: Mapping[str, str], style: ValueStyle) -> tuple[dict[str, str], bool]:
    rendered: dict[str, str] = {}
    wrote_literal = False
    for name, value in headers.items():
        rendered[name], literal = render_value(value, style)
        wrote_literal = wrote_literal or literal
    return rendered, wrote_literal


class JsonClientAdapter:
    """A client whose MCP servers live under one top-level key of a JSON file."""

    name: str
    display_name: str
    reload_hint: str
    root_key = "mcpServers"

    def config_path(self) -> Path:
        raise NotImplementedError

    def detect(self) -> bool:
        return self.config_path().parent.is_dir()

    def build_block(self, entry: ServerEntry) -> tuple[dict[str, Any], list[str]]:
        """The JSON block for `entry`, plus warnings. May raise ConfigError."""
        raise NotImplementedError

    def url_of(self, block: Mapping[str, Any]) -> str | None:
        return block.get("url")

    def check_entry(self, block: Mapping[str, Any]) -> str | None:
        return None

    def list_entries(self) -> dict[str, dict[str, Any]]:
        try:
            data = load_json(self.config_path())
        except ConfigError:
            return {}
        servers = data.get(self.root_key)
        return servers if isinstance(servers, dict) else {}

    def install(self, entry: ServerEntry, *, replace: bool = False, force: bool = False) -> InstallResult:
        path = self.config_path()

        def result(status: Status, message: str = "") -> InstallResult:
            return InstallResult(self.name, status, str(path), message)

        try:
            block, warnings = self.build_block(entry)
        except ConfigError as exc:
            return result("failed", str(exc))
        snippet = json.dumps({self.root_key: {entry.name: block}}, indent=2)

        try:
            data = load_json(path)
        except ConfigError as exc:
            if not force:
                return result(
                    "failed",
                    f"{exc}. Fix the file, re-run with --force (a .bak backup is kept), "
                    f"or add this manually:\n{snippet}",
                )
            data = {}

        servers = data.setdefault(self.root_key, {})
        if not isinstance(servers, dict):
            return result("failed", f"'{self.root_key}' in {path} is not an object; add this manually:\n{snippet}")
        existed = entry.name in servers
        if existed and not replace:
            return result("skipped", f"'{entry.name}' already exists (pass --yes to replace)")

        servers[entry.name] = block
        try:
            write_json_atomic(path, data)
        except OSError as exc:
            return result("failed", f"could not write {path} ({exc}); add this manually:\n{snippet}")
        return result("replaced" if existed else "installed", "; ".join(warnings))
```

```python
"""Claude Code: registered through its own `claude mcp add` CLI rather than by editing ~/.claude.json."""

from __future__ import annotations

import shlex
import shutil
import subprocess
from pathlib import Path

from mcpmaker.clients.base import InstallResult, ServerEntry
from mcpmaker.configio import ConfigError, load_json


class ClaudeCodeAdapter:
    name = "claude-code"
    display_name = "Claude Code"
    reload_hint = "Claude Code: start a new session (or run /mcp) to pick up the server"

    def __init__(self, runner=subprocess.run) -> None:
        self._run = runner

    def _exe(self) -> str | None:
        return shutil.which("claude")

    def detect(self) -> bool:
        return self._exe() is not None

    def config_path(self) -> Path:
        return Path.home() / ".claude.json"

    def list_entries(self):
        try:
            data = load_json(self.config_path())
        except ConfigError:
            return {}
        servers = data.get("mcpServers")
        return servers if isinstance(servers, dict) else {}

    def url_of(self, block):
        return block.get("url")

    def check_entry(self, block):
        return None

    def _add_args(self, entry: ServerEntry) -> list[str]:
        args = ["mcp", "add", "--transport", "http", "--scope", "user", entry.name, entry.url]
        for name, value in entry.headers.items():
            args += ["--header", f"{name}: {value}"]
        return args

    def install(self, entry: ServerEntry, *, replace: bool = False, force: bool = False) -> InstallResult:
        exe = self._exe()
        path = str(self.config_path())
        if exe is None:
            manual = shlex.join(["claude", *self._add_args(entry)])
            return InstallResult(self.name, "failed", path, f"`claude` is not on PATH; run this yourself:\n{manual}")
        existed = entry.name in self.list_entries()
        if existed:
            if not replace:
                return InstallResult(self.name, "skipped", path, f"'{entry.name}' already exists (pass --yes to replace)")
            self._run([exe, "mcp", "remove", "--scope", "user", entry.name], capture_output=True, text=True)
        proc = self._run([exe, *self._add_args(entry)], capture_output=True, text=True)
        if proc.returncode != 0:
            return InstallResult(self.name, "failed", path, (proc.stderr or "").strip() or "claude mcp add failed")
        return InstallResult(self.name, "replaced" if existed else "installed", path)
```

```python
@dataclass
class ProbeResult:
    connected: bool
    server_name: str | None = None
    tools: list[str] = field(default_factory=list)
    call_ok: bool | None = None
    error: str | None = None
    status_code: int | None = None


async def probe(
    url: str, headers: Mapping[str, str], call_tool: str | None = None, timeout: float = 10.0
) -> ProbeResult:
    """Connect to an MCP endpoint like a client would and report what works."""
    transport = StreamableHttpTransport(url, headers=dict(headers))
    try:
        async with Client(transport, timeout=timeout) as client:
            info = client.initialize_result.serverInfo
            result = ProbeResult(connected=True, server_name=info.name)
            result.tools = [tool.name for tool in await client.list_tools()]
            if call_tool:
                called = await client.call_tool(call_tool, {}, raise_on_error=False)
                result.call_ok = not called.is_error
                if called.is_error:
                    result.error = " ".join(getattr(c, "text", "") for c in called.content).strip()
            return result
    except Exception as exc:
        return ProbeResult(connected=False, error=f"{type(exc).__name__}: {exc}", status_code=_find_status(exc))


def _find_status(exc: BaseException) -> int | None:
    """Dig an HTTP status out of nested/grouped exceptions raised by the MCP client."""
    stack, seen = [exc], set()
    while stack:
        current = stack.pop()
        if id(current) in seen:
            continue
        seen.add(id(current))
        if isinstance(current, httpx.HTTPStatusError):
            return current.response.status_code
        stack.extend(getattr(current, "exceptions", ()) or ())
        stack.extend(e for e in (current.__cause__, current.__context__) if e is not None)
    return None
```

```python
"""`mcpmaker doctor`: check the whole chain, from the /mcp endpoint to each client's config."""

import asyncio
from dataclasses import dataclass
from typing import List, Optional

import typer

from mcpmaker.auth import parse_header
from mcpmaker.clients import all_adapters
from mcpmaker.configio import ConfigError, render_value
from mcpmaker.engine import probe


@dataclass
class Check:
    name: str
    status: str  # "OK" | "FAIL" | "--"
    detail: str = ""


def resolve_headers(raw: List[str]) -> dict:
    headers = {}
    for item in raw:
        try:
            name, value = parse_header(item)
            headers[name], _ = render_value(value, "literal")
        except (ValueError, ConfigError) as exc:
            raise typer.BadParameter(str(exc), param_hint="--header")
    return headers


def run_checks(url: str, headers: dict, call: Optional[str]) -> List[Check]:
    checks: List[Check] = []
    result = asyncio.run(probe(url, headers, call_tool=call))
    if not result.connected:
        if result.status_code in (401, 403):
            fix = f"the endpoint answered HTTP {result.status_code}; check --header and any auth middleware in front of /mcp"
        else:
            fix = "is the app running? Check the URL - it should end with the mount path, e.g. /mcp"
        checks.append(Check("MCP server reachable", "FAIL", f"{result.error}. Fix: {fix}"))
    else:
        checks.append(Check("MCP server reachable", "OK", f"server '{result.server_name}'"))
        if result.tools:
            checks.append(Check("Tools exposed", "OK", f"{len(result.tools)} tools"))
        else:
            checks.append(Check(
                "Tools exposed", "FAIL",
                "0 tools. Fix: read the mcpmaker startup log - write routes are hidden unless "
                "include_writes=True or openapi_extra={'x-mcp': True}",
            ))
        if call:
            if result.call_ok:
                checks.append(Check(f"Call {call}", "OK"))
            else:
                checks.append(Check(f"Call {call}", "FAIL", result.error or "tool returned an error"))

    for adapter in all_adapters():
        label = f"{adapter.display_name} configured"
        if not adapter.detect():
            checks.append(Check(label, "--", "not installed"))
            continue
        matches = {n: b for n, b in adapter.list_entries().items() if adapter.url_of(b) == url}
        if not matches:
            checks.append(Check(
                label, "FAIL", f"no entry points to {url}. Fix: mcpmaker connect --url {url} --client {adapter.name}"
            ))
            continue
        problems = [p for p in (adapter.check_entry(b) for b in matches.values()) if p]
        if problems:
            checks.append(Check(label, "FAIL", "; ".join(problems)))
        else:
            checks.append(Check(label, "OK", f"entry '{', '.join(matches)}'"))
    return checks


def print_checks(checks: List[Check]) -> bool:
    for check in checks:
        typer.echo(f"{check.status:<4} {check.name}" + (f": {check.detail}" if check.detail else ""))
    return any(c.status == "FAIL" for c in checks)


def doctor(
    url: str = typer.Option(..., "--url", help="The MCP endpoint, e.g. http://localhost:8000/mcp"),
    header: Optional[List[str]] = typer.Option(None, "--header", "-H", help="'Name: value'; ${VAR} is read from the environment"),
    call: Optional[str] = typer.Option(None, "--call", help="Also call this no-argument tool"),
) -> None:
    """Check that the MCP server is reachable, exposes tools, and is wired into each AI client."""
    failed = print_checks(run_checks(url, resolve_headers(header or []), call))
    if failed:
        raise typer.Exit(1)
```

```python
"""`mcpmaker connect`: register the MCP server with every installed AI client."""

import asyncio
import re
from typing import List, Optional

import typer

from mcpmaker.auth import parse_header
from mcpmaker.cli.doctor import print_checks, run_checks
from mcpmaker.clients import all_adapters
from mcpmaker.clients.base import ServerEntry
from mcpmaker.configio import ConfigError, render_value
from mcpmaker.engine import probe

DEFAULT_NAME = "api"
MARKERS = {"installed": "OK", "replaced": "OK", "skipped": "--", "failed": "FAIL"}


def slugify(text: str) -> str:
    return re.sub(r"[^a-z0-9]+", "-", text.lower()).strip("-") or DEFAULT_NAME


def _resolved(raw_headers: dict) -> dict:
    """Header values with ${VAR} expanded, for talking to the server now. Unset vars are dropped."""
    out = {}
    for name, value in raw_headers.items():
        try:
            out[name], _ = render_value(value, "literal")
        except ConfigError:
            pass
    return out


def connect(
    url: str = typer.Option(..., "--url", help="The MCP endpoint, e.g. http://localhost:8000/mcp"),
    header: Optional[List[str]] = typer.Option(None, "--header", "-H", help="'Name: value'; use ${VAR} to keep secrets in env vars"),
    name: Optional[str] = typer.Option(None, "--name", help="Server name in client configs (default: from the server)"),
    client: Optional[List[str]] = typer.Option(None, "--client", help="Only these clients (repeatable)"),
    all_: bool = typer.Option(False, "--all", help="Set up every detected client without asking"),
    yes: bool = typer.Option(False, "--yes", "-y", help="Don't prompt; replace existing entries"),
    force: bool = typer.Option(False, "--force", help="Overwrite config files that aren't valid JSON (a .bak is kept)"),
) -> None:
    """Add this MCP server to Claude Code, Cursor, VS Code, Windsurf, and Claude Desktop."""
    raw_headers = {}
    for item in header or []:
        try:
            key, value = parse_header(item)
        except ValueError as exc:
            raise typer.BadParameter(str(exc), param_hint="--header")
        raw_headers[key] = value

    if name is None:
        found = asyncio.run(probe(url, _resolved(raw_headers)))
        if found.connected and found.server_name:
            name = slugify(found.server_name)
        else:
            name = DEFAULT_NAME
            typer.echo(f"note: {url} is not reachable right now; using server name '{name}' (pass --name to choose)")
    entry = ServerEntry(name=name, url=url, headers=raw_headers)

    adapters = all_adapters()
    if client:
        by_name = {a.name: a for a in adapters}
        unknown = [c for c in client if c not in by_name]
        if unknown:
            raise typer.BadParameter(
                f"unknown client(s): {', '.join(unknown)}. Known: {', '.join(by_name)}", param_hint="--client"
            )
        chosen = [by_name[c] for c in client]
    else:
        typer.echo("Detected AI clients:")
        detected = []
        for adapter in adapters:
            found_client = adapter.detect()
            typer.echo(f"  {'OK' if found_client else '--':<4} {adapter.display_name}" + ("" if found_client else " (not installed)"))
            if found_client:
                detected.append(adapter)
        if not detected:
            typer.echo("No supported AI clients found. Use --client <name> to write a config anyway.")
            raise typer.Exit(1)
        if all_ or yes:
            chosen = detected
        else:
            chosen = [a for a in detected if typer.confirm(f"Set up {a.display_name}?", default=True)]

    failed = False
    for adapter in chosen:
        replace = yes
        if not yes and name in adapter.list_entries():
            replace = typer.confirm(f"{adapter.display_name} already has a server named '{name}'. Replace it?", default=False)
        result = adapter.install(entry, replace=replace, force=force)
        typer.echo(f"{MARKERS[result.status]:<4} {adapter.display_name}: {result.status}" + (f" ({result.path})" if result.path else ""))
        if result.message:
            typer.echo(f"     {result.message}")
        if result.status in ("installed", "replaced"):
            typer.echo(f"     next: {adapter.reload_hint}")
        failed = failed or result.status == "failed"

    if not yes and typer.confirm("Run mcpmaker doctor now?", default=True):
        print_checks(run_checks(url, _resolved(raw_headers), None))
    if failed:
        raise typer.Exit(1)
```

```python
"""`mcpmaker bridge`: stdio <-> HTTP relay for clients that only launch local processes."""

import os
import re
from typing import List, Mapping, Optional

import typer

from mcpmaker.auth import parse_header
from mcpmaker.engine import run_stdio_bridge

_HEADER_VAR = re.compile(r"^MCPMAKER_HEADER_(\d+)$")


def headers_from_env(environ: Mapping[str, str]) -> dict:
    numbered = sorted(
        (int(m.group(1)), value) for key, value in environ.items() if (m := _HEADER_VAR.match(key))
    )
    return dict(parse_header(value) for _, value in numbered)


def bridge(
    url: str = typer.Option(..., "--url", help="The MCP endpoint to relay to"),
    header: Optional[List[str]] = typer.Option(None, "--header", "-H", help="'Name: value' (also read from MCPMAKER_HEADER_<N>)"),
) -> None:
    """Relay MCP over stdio to an HTTP endpoint (used by Claude Desktop)."""
    headers = headers_from_env(os.environ)
    for item in header or []:
        try:
            key, value = parse_header(item)
        except ValueError as exc:
            raise typer.BadParameter(str(exc), param_hint="--header")
        headers[key] = value
    run_stdio_bridge(url, headers)
```

```python
"""Build a standalone MCP server from an OpenAPI document (for APIs whose code you don't control)."""

from __future__ import annotations

import json
from pathlib import Path
from typing import Any, Mapping, Sequence

import httpx
import yaml

from mcpmaker.auth import PassThroughAuth
from mcpmaker.engine import build_server, make_api_client
from mcpmaker.policy import ensure_operation_ids, operations_from_spec, select_operations
from mcpmaker.report import MountReport


def load_spec(source: str) -> dict[str, Any]:
    if source.startswith(("http://", "https://")):
        response = httpx.get(source, timeout=30.0, follow_redirects=True)
        response.raise_for_status()
        text = response.text
    else:
        text = Path(source).read_text(encoding="utf-8-sig")
    try:
        data = json.loads(text)
    except json.JSONDecodeError:
        data = yaml.safe_load(text)
    if not isinstance(data, dict) or not isinstance(data.get("paths"), dict):
        raise ValueError(f"{source} does not look like an OpenAPI document (no 'paths' object)")
    return data


def build_standalone_app(
    spec: Mapping[str, Any],
    *,
    base_url: str,
    name: str | None = None,
    include_writes: bool = False,
    exclude: Sequence[str] = (),
    forward_headers: Sequence[str] = (),
    path: str = "/mcp",
):
    spec = ensure_operation_ids(spec)
    selection = select_operations(
        operations_from_spec(spec), include_writes=include_writes, exclude=exclude, mount_path=path
    )
    client = make_api_client(base_url=base_url, auth=PassThroughAuth(forward_headers))
    title = name or (spec.get("info") or {}).get("title") or "API"
    server, skipped = build_server(spec, name=title, selection=selection, client=client)
    report = MountReport.from_selection(selection, path=path, skipped=skipped)
    return server.http_app(path=path), report
```

```python
from typing import List, Optional

import typer
import uvicorn

from mcpmaker.standalone import build_standalone_app, load_spec


def serve(
    spec: str = typer.Argument(..., help="OpenAPI JSON/YAML file path or URL"),
    base_url: str = typer.Option(..., "--base-url", help="Where the real API lives, e.g. https://api.example.com"),
    include_writes: bool = typer.Option(False, "--include-writes", help="Also expose POST/PUT/PATCH/DELETE"),
    exclude: Optional[List[str]] = typer.Option(None, "--exclude", help="Path glob to hide, e.g. '/admin/*'"),
    forward_header: Optional[List[str]] = typer.Option(None, "--forward-header", help="Extra header name to pass through"),
    host: str = typer.Option("127.0.0.1", "--host"),
    port: int = typer.Option(8765, "--port"),
    path: str = typer.Option("/mcp", "--path"),
) -> None:
    """Run a standalone MCP server that proxies tool calls to an existing HTTP API."""
    try:
        document = load_spec(spec)
    except (OSError, ValueError) as exc:
        raise typer.BadParameter(str(exc), param_hint="SPEC")
    app, report = build_standalone_app(
        document,
        base_url=base_url,
        include_writes=include_writes,
        exclude=exclude or [],
        forward_headers=forward_header or [],
        path=path,
    )
    typer.echo(report.format())
    typer.echo(f"MCP endpoint: http://{host}:{port}{path}")
    uvicorn.run(app, host=host, port=port)
```

````markdown
# mcpmaker

Turn your FastAPI app into an MCP server with one line, then connect it to every AI client with one command.

## Install

```bash
pip install mcpmaker
```

## 1. Add it to your app

```python
from fastapi import FastAPI
from mcpmaker import mount_mcp

app = FastAPI()
# ... your routes ...
mount_mcp(app)   # serves MCP at /mcp
```

At startup you'll see what the AI can use:

```
mcpmaker: 12 tools exposed at /mcp (7 write routes hidden - pass include_writes=True or mark routes)
```

**Safe by default:** only GET routes become tools. To expose writes:

```python
mount_mcp(app, include_writes=True)                   # all writes
@app.post("/items/{id}/star", openapi_extra={"x-mcp": True})   # just this one
mount_mcp(app, exclude=["/admin/*"])                  # hide paths
```

Auth: the `Authorization` and `Cookie` headers sent by the AI client are passed to your routes, so your existing auth keeps working. Add more with `forward_headers=["X-API-Key"]`.

## 2. Connect your AI clients

```bash
mcpmaker connect --url http://localhost:8000/mcp --header "Authorization: Bearer ${API_TOKEN}"
```

This detects Claude Code, Cursor, VS Code, Windsurf, and Claude Desktop, and adds the server to each. It never clobbers your other servers, and it keeps a `.bak` of every file it touches. Where a client supports it, `${API_TOKEN}` stays an env-var reference instead of a pasted secret.

## 3. Check everything works

```bash
mcpmaker doctor --url http://localhost:8000/mcp
```

## No access to the API's code?

```bash
mcpmaker serve ./openapi.json --base-url https://api.example.com
```
````
